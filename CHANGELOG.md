# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic
versioning.

## [0.1.0] - 2026-08-21

### Added

- Offline PNG/JPEG/WebP/BMP/TIFF loading with byte, frame and pixel limits.
- Independent OpenCV and ZXing-C++ baseline and degradation decoding.
- Quiet-zone, contrast, module scaling and optional printer-dot findings.
- Deterministic quick/print profiles covering blur, JPEG, downsampling and low contrast.
- Text, versioned JSON and self-contained HTML reports with stable exit codes.
- Reproducible healthy, cropped and low-contrast examples plus a real-result robustness grid.
