# Example assets

All PNG files are generated by `uv run python scripts/make_examples.py` with the payload
`https://github.com/KanadeK/qrflight`.

- `healthy.png`: six white modules surround the QR; both decoders read it.
- `cropped.png`: only two white modules remain; QRFlight reports `QUIET_ZONE_TOO_SMALL`.
- `low-contrast.png`: black/white levels are 100/180; QRFlight reports `CONTRAST_TOO_LOW` and
  preserves any real decoder disagreement.

The robustness grid in `docs/assets/robustness-grid.png` is generated from the `print` profile.
Every status is the result of decoding that exact transformed image with OpenCV and ZXing-C++.
